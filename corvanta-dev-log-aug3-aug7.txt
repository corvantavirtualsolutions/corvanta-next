AUG 6
------

8. VA Application wizard overhaul
   - Intro step: Corvanta logo centered above title, full comfortable spacing restored
   - Removed duplicate logo from top-left sticky bar (bar now hidden on step 0)
   - Added City + Country as separate required fields (joined as "City, Country" on submit)
   - Niche/Specialization: dropdown with predefined options + "Other" free-text reveal
   - Skills & Tools: checkbox grid with "Other" free-text reveal
   - URL validation on portfolio, LinkedIn, and Facebook fields
   - Video countdown reduced from 5 seconds to 3 seconds

9. English Proficiency and IQ tests built into the wizard
   - Created data/english-test.md (30 questions: Grammar, Vocabulary, Reading Comprehension,
     Business English, 3 Writing prompts)
   - Created data/iq-test.md (30 questions: Logical Reasoning, Numerical, Abstract,
     Probability)
   - New TestModal component: one question at a time, per-question countdown timers,
     auto-advance at zero, immediate advance on MC answer click
   - Intro disclaimer screen before each test starts
   - Timer colors: accent (normal) -> yellow (<=20s) -> red (<=10s) with pulse animation
   - Reading comprehension questions show the passage above the question
   - Writing questions (3 min each): textarea + Submit Answer button
   - Timer durations: Grammar/Business English 30s, Reading Comprehension 45s,
     Writing 180s, IQ 45s each
   - Both tests must be completed before the applicant can proceed past step 2
   - Scores are hidden from the applicant; saved to Supabase on final submit:
       english_mc_score  (integer, out of 27 auto-graded MC questions)
       english_writing_1 (text)
       english_writing_2 (text)
       english_writing_3 (text)
       iq_score          (integer, out of 30)
   - Supabase: run the following to add the columns if not yet present:
       ALTER TABLE va_applications
         ADD COLUMN IF NOT EXISTS english_mc_score   integer,
         ADD COLUMN IF NOT EXISTS english_writing_1  text,
         ADD COLUMN IF NOT EXISTS english_writing_2  text,
         ADD COLUMN IF NOT EXISTS english_writing_3  text,
         ADD COLUMN IF NOT EXISTS iq_score           integer;

10. Admin detail modal: Test Scores section
    - Shows English MC score as "X / 27" with CEFR interpretation label:

        18-22   Intermediate (B1)

    - Shows IQ score as "X / 30" with interpretation label:
        27-30   Exceptional reasoning ability
        24-26   Strong analytical skills
        20-23   Above average; suitable for most VA roles
        15-19   Average; may require more training
        <15     Consider additional evaluation
    - Shows all three writing answers (manually graded by admin)

11. Storage cleanup on application delete
    - Deleting a VA application from the admin dashboard now also removes the
      associated files from the va-videos Supabase Storage bucket:
      profile photo, intro video, skills video, and answer video
    - Best-effort: row delete still succeeds if a storage file is already gone
    - VA Seeker and Review deletes confirmed to have no associated storage files
